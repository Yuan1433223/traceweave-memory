# 数据模型与一致性

2026-10-25。SQLite schema v1；候选注释/关联层在相应切片再建表。当前存储实现见 `src/traceweave_memory/adapters/sqlite.py`。

## B0 物理模型

| 表/目录 | 内容与约束 |
|---|---|
| requests | user_id + request_id 联合主键；body_hash、session_id、READY |
| evidence | 稳定 ID、请求与消息位置、原始 content 的私有媒体引用形式、role、source_timestamp、created_at、媒体字节数、词频与长度 |
| lexical | FTS5 预分词 tokens，以 evidence.row_id 对应；与证据同事务写入 |
| media/ | user_id 的 SHA256 目录 + 媒体字节 SHA256 文件；不使用用户字符串拼文件路径 |

Evidence ID = `mem_` + SHA256([user_id, request_id, 消息位置] 的规范 JSON)。数据库同时约束 `(user_id,id)` 与 `(user_id,request_id,position)` 唯一。请求哈希覆盖角色、顺序、所有内容和来源时间；非语义性 JSON 键顺序不影响哈希，不 strip 原文或标识符。

content 字符串逐字保存；有序数组只把 image_url 替换成内部 digest/subtype/size，读出时恢复原图 Data URI。保存与回传的图像字节相同；不承诺保留非规范 Base64 编码的字符串形式。文本位置和多图顺序保留，来源消息角色与时间单独存储。

有 source_timestamp 时 created_at 是其 UTC 表示；无时间时 created_at 为登记时间，source_timestamp 仍为空，不能把登记时间用于推断事件发生。Mem-Gallery 的仅日期来源在本地适配中按 UTC 零点转换，原日期精度不可当作准确时分。

所有数据库连接启用外键；请求/消息/FTS 事务一起成功或回滚。媒体先写入，因此回滚可能留下孤立文件；不会有成功记录指向未写完的文件。读出发现媒体丢失或哈希不符返回503，不静默改成纯文本成功。

## 隔离与生命周期

user_id 是唯一检索边界，session_id 组织来源。媒体和稳定 ID 都包含作用域，评分统计也在作用域内；跨样本相同图片不作为共享记忆。重复 Add 不改变原始 created_at 或记录数。同 request_id 不同内容视为冲突，不覆盖原证据。

schema 未知版本拒绝启动，不自动删除重建或降级；当前仅空库到 v1，后续迁移需新版本及数据转换检查。B0 没有更新/删除公共 API；正式数据仍需按规则离线清理，后续补受控管理用例。

## 后续逻辑实体

Annotation 保存 evidence_ids、类型、值、来源、支持片段、模型/prompt版本与不确定性；Assertion 保存实体、属性、时间区间、声明时间与更新依据；Link 保存有来源的关系。原始证据永久独立于可重建索引，未知字段不填伪默认值。历史状态不因新声明被无记录覆盖。
