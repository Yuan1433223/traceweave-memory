## 依赖与职责

```text
API / CLI → application → domain + ports
bootstrap → adapters → ports
evaluation → 同一 application（生产代码不反向导入 evaluation）
```

- `domain.py`：稳定 ID、词法 token、证据与确定性限制；不导入框架、模型或数据库。
- `ports.py`：当前已使用的仓储与媒体 I/O。
- `application.py`：校验完整逻辑写入、保存媒体、事务落库、召回与原内容重建。
- `adapters/sqlite.py`：B0 元数据与 FTS5 同库事务，作用域内 BM25。
- `adapters/media.py`：Data URI 解码、实际图像验证、内容寻址持久化和完整性检查。
- `api/schemas.py`：严格官方类型；`bootstrap.py` 组装 API、认证和错误映射；`config.py` 读环境。
- `evaluation/`：公开数据转换、来源映射和离线检索；标签仅在评估器侧读取。
- `adapters/models/deepseek.py` 与 `adapters/budget.py`：独立模型调用与预算 I/O；`evaluation/model_check.py` 用合成材料检查契约，未接入 MemoryService。

## B0 路径

Add：严格入参 → 校验所有图片/时间 → 私有媒体原字节持久化 → SQLite 请求/消息/FTS 一次事务 → HTTP 200。

请求以 `(user_id, request_id)` 与完整请求哈希实现幂等。相同请求复用已存结果，变更正文返回409；媒体先于数据库写入，失败可能留下无引用媒体文件，但失败证据不可检索。重试可复用媒体；当前不做自动垃圾回收。

B0 无模型、无需向量；RAW_STORED/INDEXED 到 READY 收敛为同库事务，不以虚构的空阶段表代替一致性。后续模型/向量阶段需显式持久化进度与恢复，不能假定跨库事务或模型计费 exactly-once。

Search：从 query 的文本部分提取 tokens → FTS 匹配并限定 user_id → scope 内 BM25 → top_k → 在30 MiB图片预算下保留完整记录 → 校验媒体哈希并封装原始图文。

BM25 的 N、平均长度、文档频率只用同 scope 数据，避免其他样本影响排序或分数。词法采用 Unicode 单词及中文单/双字；无停用词、词干化、语义或视觉推理。图片查询通过格式校验，但 B0 不理解图片；纯图查询返回空，不编造 caption。options 暂不用于 B0。

图片预算超限时跳过完整记录，后续较小记录可继续；不悄悄删除一条来源中的图片或裁剪原图。当前不精确估算 Answer 视觉 token，仅执行官方媒体与数量上限，因此不是最终预算选择算法。

原图、原文与注释分别存储；每次增强由 [评测方案](评测方案.md) 的 B0—B5 对照决定采纳。模型和向量适配独立于业务用例，不复制通用 SDK 或引入不必要编排框架。

## 模型调用与预算

DeepSeek 能力与价格核对日期为2026-10-25：[官方模型表](https://api-docs.deepseek.com/quick_start/pricing/)、[视觉指南](https://api-docs.deepseek.com/guides/vision/)。当日旧名deepseek-v4-flash路由至V4.1-Flash-1017，适配使用deepseek-flash；响应别名不证明精确后端快照。价格变化后需重新核对并更新假设。

- ModelSettings 校验配置且密钥不进 repr；只接受官方 HTTPS 端点，不跟随重定向或回退供应商/模型。密钥由显式 `uv run --env-file .env` 加载，不从示例文件寻找。图片仅放 user 消息，HTTP 请求限48 MiB。
- 每项最多2次尝试；仅网络错误、408/429及指定5xx重试，每次独立预留。认证、输出截断、陌生模型、无效JSON/schema不自动重试，错误不回显上游正文。
- 固定账本 `data/model-budget.sqlite3`，立即事务保护并发预留，跨运行共用；配置只能降低已存上限。每次按完整1,048,576输入token窗口加当前输出上限预留，避免猜测图文token数。
- 收到合法usage先结算再验输出；按缓存命中/未命中/输出每百万token分别0.006/0.30/1.20美元的峰时价格逐请求向上取整。超时、缺usage或中断保留占额；usage超过预留仍记费并封锁后续调用。
- 账本仅存任务类别、模型标识、用量、价格版本与状态，不存提示、图片、密钥、模型正文或思考链。预算库schema v1使用policy/attempts，与记忆库独立。

金额是固定价格与窗口假设下的估算，不能约束项目外调用、删除账本/换目录后的预算或供应商价格变化；无账单对账、未知费用手工结算和预算重置命令。授权上限见 TODO，历史调用结果见 [D.1记录](验收记录/D.1-2026-10-25.md)。

## 当前部署边界

单进程、单机持久卷，Python 3.12。SQLite 写入事务串行化；媒体按哈希原子替换并验证重复目标，覆盖 Windows 并发同请求场景。尚未验证多进程、网络文件系统、大规模吞吐或断电级持久化。Body 中间件限制实际 HTTP 字节（含 chunked），默认64 MiB是本地资源配置，不是 AML 统一字符限制；超限413。
