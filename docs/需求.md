# 需求与验收

2026-10-25。用户已认可总体架构，授权按 A—F 切片推进；任务状态见 [TODO](../TODO.md)。

## 目标

实现可复现的多模态长期记忆服务，参加 AML 第二期开源方法多模态赛道。服务接收图文历史、维护隔离的可追溯证据，并返回相关原始记忆；最终回答和正式评分由 AML 运行。

用户确认的方向：原始图文保真、多视角结构化索引、混合召回、按需时序与实体关联、原图核验及证据预算选择。各增强的收益尚需消融，方向认可不等于所有模块默认开启。

## 验收要求

| 编号 | 要求 | 验证 |
|---|---|---|
| R-01 | Add/Search 接受官方字符串或有序 text/image_url 内容数组 | API 合约、媒体限制、原顺序和原图字节回传 |
| R-02 | 完全相同的 user_id 为唯一检索边界 | 跨 scope 相同局部 ID、媒体与评分统计隔离 |
| R-03 | 写入成功后可立即检索，重复请求不重复写入 | 事务、重复/冲突、重启及故障注入 |
| R-04 | 原文、视觉注释、推断与历史状态分开 | 来源字段、引用回查、时间与索引版本检查 |
| R-05 | Search 只返回已有证据，不生成最终答案 | ID 白名单及原始内容比较 |
| R-06 | 每个增强有相同输入、预算与留出集上的对照 | 本地检索、完整覆盖、回答质量与费用分开报告 |
| R-07 | 数据与运行可复现、可清理，秘密不入库 | 依赖锁、数据 manifest、scope 与输出目录边界 |
